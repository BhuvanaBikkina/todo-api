# To-Do List Web Application

## Overview
A simple To-Do List web application built using Spring Boot, Java, HTML, CSS, and JavaScript.

## Features
* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Simple and user-friendly interface

## Technologies Used
* Java
* Spring Boot
* Maven
* HTML
* CSS
* JavaScript

## Future Enhancements
* Task priorities
* Due dates
* User authentication
* Dark mode
* Database integration

## How to Run
1. Clone the repository
2. Run `mvn spring-boot:run`
3. Open `http://localhost:8080`
